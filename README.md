# Система онлайн-записи в автосервис

Лабораторные работы по дисциплине МиСПИСИТ. Текущая версия — 0.0.2 (лабораторная работа №2: три главные функции и страницы проекта).

Стек: Python 3.13, Django 5.2.19, шаблоны Django. Данные хранятся в JSON-файлах папки `data/`.

## Страницы

| Адрес | Что на странице |
|---|---|
| `/` | Главная: название, услуги, переходы к действиям |
| `/bookings/new/` | Форма записи на обслуживание (создание данных) |
| `/bookings/` | Список всех записей (просмотр) |
| `/bookings/1/` | Карточка одной записи |
| `/bookings/rejected/` | Отказ в записи и журнал отказов (ошибочный сценарий) |

Пример отказа: запишитесь к мастеру «Петров Сергей» на 21.12.2026 в 11:00. В это время у него уже есть запись №1, и система откажет.

```bash

docker run --rm -p 8080:8080 yaganovvadimkargb/mispisit-labs:0.0.2
```

После запуска приложение доступно по адресу http://localhost:8080
